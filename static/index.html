    เริ่มจากตั้งค่า แล้วสร้างแชตใหม่

    ใส่ OpenRouter key และเลือกโมเดล 3 ตัว: ตัวสรุป ตัววิ่งหาข้อมูล และตัวทำงานหลัก

    Enter ส่ง · Shift+Enter ขึ้นบรรทัดใหม่

    ตั้งค่า

    ทุกอย่างเก็บในเครื่องนี้ที่ data/memory.db key ส่งไปที่ OpenRouter เท่านั้น

    โมเดล

    คิดมากขึ้น ตอบช้าและแพงขึ้น ใช้ได้เฉพาะโมเดลที่รองรับ reasoning แต่ละแชตปรับเองได้ที่ช่องพิมพ์

    ค่าระบบ

    ค่าเหล่านี้คือค่าเริ่มต้นของทุกแชต แต่ละแชตตั้งค่าเฉพาะของตัวเองได้จากปุ่ม "ปรับ" ที่หัวแชต

    ปักเป็นเงื่อนไข (condition)

    ต้องเป็นคำของคุณตรงตัว ลบส่วนที่ไม่ต้องการออกได้ แต่ห้ามแก้คำ

    การบีบอัดของแชตนี้

    เว้นว่างไว้เพื่อใช้ค่าเริ่มต้นของระบบ ตั้งเฉพาะแชตนี้ได้ถ้าต้องการค่าต่างจากแชตอื่น
